# Participant Instructions

> Draft for distribution with the planned Chrome Web Store release.

Use these steps to export the Replika chat log requested by the research team.

## Before You Start

Have these items ready:

- Google Chrome on a computer;
- your Replika login;
- the Chrome Web Store link from the research team;
- your assigned Participant ID;
- your assigned From date and To date;
- the study's file-submission instructions.

## Install The Extension

1. Open the Chrome Web Store link provided by the research team.
2. Click **Add to Chrome**.
3. Click **Add extension** to confirm.
4. Open Chrome's Extensions menu and select **CompanionLink**.

## Export Your Chat Log

1. In Chrome, go to [my.replika.com](https://my.replika.com) and sign in.
2. Refresh the Replika page and wait for the chat to load.
3. Open **CompanionLink**.
4. Enter the Participant ID provided by the research team.
5. Select the provided **From date** and **To date**.
6. Click **Export Chat Log**.
7. Keep the Replika tab and extension open while the export runs.
8. Wait until the extension displays `Downloaded P<Participant ID>.csv`.
9. Confirm that the file is in Chrome's Downloads folder.

Both selected dates are included and use your computer's time zone automatically. Check that your computer's time zone is correct before exporting. If the To date is today, the export includes messages through the time you click **Export Chat Log**.

## Submit The File

Submit the downloaded chat log file using the method provided by the research team.

## Troubleshooting

### The extension asks you to open Replika

Make sure the active tab's address is my.replika.com (not replika.com), confirm that you are signed in, and try again without switching tabs.

### The Replika session was not captured

Refresh the Replika tab, wait for the chat to load, then try again.

### The file did not download

Check Chrome's Downloads page and any download warning. Retry the export and keep the extension open until it confirms the download.

### The export stopped or showed another error

Refresh Replika and retry once with the same Participant ID and dates. If the problem continues, send the exact error message to the research team.
