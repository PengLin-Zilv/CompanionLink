# Participant Instructions: Claude

> This guide covers Claude; see the [Replika](../replika/participant-guide.md) and [Kindroid](../kindroid/participant-guide.md) instructions for those apps.

Use these steps to export the Claude chats requested by the research team.

## Before You Start

Have these items ready:

- Google Chrome on a computer;
- your Claude login;
- the Chrome Web Store link from the research team;
- your assigned Participant ID;
- your assigned From date and To date;
- the study's file-submission instructions.

## Install The Extension

1. Open the Chrome Web Store link provided by the research team.
2. Click **Add to Chrome**.
3. Click **Add extension** to confirm.
4. Open Chrome's Extensions menu and select **CompanionLink**.

If CompanionLink is already installed, Chrome updates it automatically. If, on a
Claude chat, CompanionLink asks you to open Replika or Kindroid without mentioning Claude,
remove CompanionLink and install it again from the link.

## Export Each Chat

CompanionLink exports one chat at a time: the chat open in the tab. **Export each chat
the research team asked you to share.** If you are not sure whether a chat counts,
ask the team first. You never have to share a chat you do not want to.

1. In Chrome, go to [claude.ai](https://claude.ai) and sign in.
2. Open one of the chats you are sharing. Its address starts with
   `claude.ai/chat/`.
3. If Claude is still replying, wait until it finishes.
4. Open **CompanionLink**.
5. Enter the Participant ID provided by the research team.
6. Select the provided **From date** and **To date**.
7. Click **Export Chat Log**.
8. Keep the extension window open until it displays
   `Downloaded P<Participant ID>.csv`. This usually takes a few seconds.
9. Repeat steps 2-8 for each other chat you are sharing. CompanionLink
   shows the same message each time, but Chrome saves the next files as
   `P<Participant ID> (1).csv`, `P<Participant ID> (2).csv`, and so on. Keep all of
   them. If Chrome asks where to save a file, do not replace an earlier one.

Both selected dates are included and use your computer's time zone automatically. Check that your computer's time zone is correct before exporting. If the To date is today, the export includes messages through the time you click **Export Chat Log**.

## Submit The Files

You can open each file before submitting it to see exactly what it contains. Submit
the files using the method provided by the research team, and tell the team how many
chats you exported.

## Troubleshooting

### "Open Replika, a one-to-one Kindroid chat or a Claude chat in this tab..."

Open the chat itself: its address starts with `claude.ai/chat/`. A new chat, the
list of chats, a project page or a shared link cannot be exported. Then click the
extension again.

### "Sign in to Claude in this tab, refresh the page, then try again."

Sign in to Claude in the same tab, refresh the page, then export again.

### "Claude has not finished its last reply in this chat..."

Wait until Claude's reply is complete. If the reply stopped with an error, click
**Retry** in Claude. Then export again.

### "Claude could not find this chat..."

Open the chat again from Claude's sidebar, check that you are signed in to the
account you use for the study, then export again.

### "Claude is limiting requests..."

Wait a few minutes, then export again.

### The extension closed before the download

Nothing was saved. Open the extension again, enter the same Participant ID and dates,
and export again.

### Another error

Refresh the Claude page and try once more. If the problem continues, send the exact
error message to the research team.
